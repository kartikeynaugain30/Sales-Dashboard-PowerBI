📊 Sales Analysis Dashboard - Power BI

About the Project
I created this **Sales Analysis Dashboard using Power BI** to analyze sales performance and understand important business insights.
The dashboard focuses on tracking sales, profit, orders, and category-wise performance through interactive visuals and KPI cards.

Tools Used
* Microsoft Power BI
* Data Visualization
* Data Analysis

Dashboard Highlights
* Overview of total sales and profit
* Category-wise sales and profit analysis
* Interactive charts for better understanding
* KPI cards for quick performance tracking
* Business insights from sales data
